# HANDS JARVIS Silver

A HANDS Tool Store instruction module for the **separate** AGPL-3.0 Roamies-derived silver JARVIS desktop companion. The Tool Store module contains no binaries and does not install the companion automatically.

For source, patch and build/launch instructions, see [`runtime/hands-jarvis-silver/`](../../runtime/hands-jarvis-silver/README.md). Attribution: [KenKaiii/Roamies](https://github.com/KenKaiii/Roamies), AGPL-3.0.
