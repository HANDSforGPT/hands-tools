# HANDS JARVIS Silver · v0.2.0

A HANDS Tool Store instruction module for an **optional, separate** JARVIS desktop companion derived from [KenKaiii/Roamies](https://github.com/KenKaiii/Roamies) (AGPL-3.0).

**Controls:** metallic animated orb, HANDS sidebar, local tool discovery, review-first command handoff, live read-only Visual Studio render progress, edge docking, microphone/action pause controls, low-power animation and one-click access to the main HANDS app. The standalone Roamies voice and screen-guidance features remain available under their original permissions.

**Important:** Installing this Tool Store module does **not** install an executable or create a privileged HANDS tool. The compiled companion is separate and must be installed or built intentionally. Command handoff copies your request and opens HANDS; you still paste and submit it there. Direct voice-to-HANDS command execution, unified Brain memory and automatic fullscreen suppression are not included in this release.
