# Contributing

Tool creation is free. Fork this repository, add packages/your-tool-id/package.json, build the registry, and open a pull request. Required checks: node scripts/build-registry.mjs, node scripts/validate.mjs. Never commit secrets, customer files, binaries, entrypoint scripts or permission bypasses. Tools are guidance only, not executable extensions. Follow the SDK and refer only to current core command names. Maintainers review changes before merging and users choose whether to download an update.
